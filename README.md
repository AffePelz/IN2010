# IN2010
The course IN2010 - Algorithms and Data Structures is about constructing effective algorithms in order to collect and compute a large set of datas. If the algorithm is not efficient, then the algorithm cannot handle any computation of thousands or millions of samples of datas. Another important topic in this course is implementation of graphs from graph theory (see https://en.wikipedia.org/wiki/Graph_theory). The general study of graph theory lies in mathematics. The repository shows different algorithms we have implemented in Python, implementation of graphs and experimenting the algorithms can handle large sets of datas.

Project 1: The first project (oblig1) are some basic tasks about implementing algorithms which can handle random sets of datas (some can be found in Kattis). In Kattis, we do not know how large the datas can be, so we have to find effective algorithms in order for them to pass Kattis tests.

Project 2: The second project (oblig2) is about implementing a graph from graph theory. The graph is about movie actors and which movies they are starring in and the graph can help us to find necessary/relevant information about each actors.

Project 3: The third project (oblig3) is about implementing four different sorting algorithms. For small and large sets of datas, we were comparing the four sorting algorithms and analysing which algorithms is the most effective one to sort a data of numbers.
